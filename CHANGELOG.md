# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-09

### Added
- Initial release of TodoMate
- Smart task management with categories
- Voice input for adding tasks
- Text-to-speech for task announcements
- Calendar view with task markers
- Habit tracking with streaks
- Dark/Light mode toggle
- Big Text accessibility mode
- Task sorting by priority, date, title, or category
- Subtasks support
- Tags and notes for tasks
- Local notifications with Yes/No action buttons
- Offline-first architecture with Hive database

### Changed
- Optimized notification system for better reliability
- Improved UI/UX across all screens

### Fixed
- Notification scheduling issues
-Habit streak calculation
- Calendar task markers

## [Unreleased]

### Planned
- Cloud sync with Firebase
- Task sharing between users
- Reminders with custom intervals
- Export tasks to CSV/PDF
- Widget support for home screen
